# LearnX Platform

## Overview
LearnX Platform is a modern educational platform with a frontend (Next.js/React) and a backend (Node.js/Express, Python ASR server).

---

## Frontend
- Built with Next.js and React
- Located in the root and `app/`, `components/`, `hooks/`, `lib/`, `public/`, `styles/`
- Features: authentication, dashboard, video learning, quizzes, flashcards, glossary, mock interview, and more

## Backend
- Located in `backend/` (Node.js/Express) and `asr-server/` (Python ASR server)
- Handles API, database, authentication, and audio transcription
- See `backend/README.md` and `asr-server/README.md` for setup
