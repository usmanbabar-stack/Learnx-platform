# LearnX Platform

A modern, full-stack educational platform designed to enhance digital learning experiences for students and educators. LearnX Platform integrates interactive video learning, quizzes, flashcards, glossary tools, and more, all within a robust and scalable architecture.

---

## 🚀 Features
- **Interactive Video Learning**: Watch, pause, and track progress on educational videos.
- **Quizzes & Flashcards**: Reinforce knowledge with built-in quizzes and flashcard tools.
- **Glossary & Mock Interviews**: Access key terms and practice interview scenarios.
- **User Authentication**: Secure sign-up, login, and password recovery.
- **Progress Tracking**: Monitor learning milestones and achievements.
- **Teacher Tools**: Upload content, manage resources, and analyze student progress.

---

## 🖥️ Frontend
- **Framework**: Next.js (React)
- **Location**: Root directory (`app/`, `components/`, `hooks/`, `lib/`, `public/`, `styles/`)
- **UI**: Responsive, modern, and accessible design

## 🛠️ Backend
- **Node.js/Express API**: Located in `backend/`
- **Python ASR Server**: Located in `asr-server/` (for audio transcription)
- **Database**: Integrated with PostgreSQL and Qdrant (vector DB)
- **Authentication**: Secure JWT-based system

---

## 📦 Getting Started
1. **Clone the repository**
2. **Install dependencies** using your preferred package manager (see `package.json` and backend/README.md)
3. **Configure environment variables** (not included for security)
4. **Run frontend and backend servers**

See `backend/README.md` and `asr-server/README.md` for detailed setup instructions.
